# Генеалогическое древо семьи Козыревых

Этот репозиторий предназначен для сбора, хранения и визуализации истории семьи.

## Содержание
- `family_tree.json` — основной файл с данными о родственниках, связях, датах и биографиях.
- В будущем: фотографии, сканы документов и другие архивные материалы.

## Как использовать
Данные из этого репозитория используются для отображения на интерактивном сайте генеалогического древа. Для добавления информации редактируйте `family_tree.json` или предлагайте изменения через Pull Request.

## Структура данных (family_tree.json)
Каждая запись содержит:
- `id`: уникальный идентификатор
- `full_name`: полное имя (включая девичью фамилию)
- `birth_date` / `death_date`: даты жизни
- `role`: роль в семье (отец, мать, дед и т.д.)
- `notes`: интересные факты, истории и примечания
- `father_id` / `mother_id`: связи с родителями для построения дерева
