# Генеалогическое древо семьи Козыревых

Проект содержит только данные о семье — без сайта и программного кода.
Основное древо хранится в файле: [`family_tree.json`](family_tree.json).

## Папки линий

- `basok-line/` — материалы исследования линии Басок: итоговый отчёт, реестры, поисковый лог и копии архивных документов.
- `kozirev-line/` — линия Козыревых/Шиловых: отчёт, реестры и сохранённые веб-артефакты; ключевая находка — запись о гибели Ивана Федоровича Козырева (1903–1943).
- `petrov-line/` — линия Петровых/Купрышкиных/Смирновых: отчёт, реестры и сохранённые веб-артефакты; документальное подтверждение военной версии пока не найдено.

## Структура файла

```json
{
  "title": "Генеалогическое древо семьи Козыревых",
  "members": [ ... ]
}
```

`title` — название древа, `members` — массив людей (сейчас 27 человек).

## Поля участника

| Поле | Обязательное | Описание |
| --- | --- | --- |
| `id` | да | Уникальный идентификатор (латиницей, без пробелов) |
| `full_name` | да | Полное имя; девичья фамилия — в скобках |
| `birth_date` | нет | Дата рождения в формате `ДД.ММ.ГГГГ` |
| `death_date` | нет | Дата смерти; если неизвестна — пометка |
| `birth_place` | нет | Место рождения |
| `role` | нет | Роль в древе относительно пробанда (отец, бабушка и т. д.) |
| `father_id` | нет | `id` отца |
| `mother_id` | нет | `id` матери |
| `spouse_id` | нет | `id` супруга/супруги |
| `children_ids` | нет | Массив `id` детей |
| `notes` | нет | Свободные заметки: биография, служба, переезды, репрессии |

## Правила заполнения

- Каждый человек описывается один раз; связи задаются только через `id`.
- `id` должен совпадать с существующим участником — иначе ссылка «повиснет».
- Связи по возможности дублируются с обеих сторон: у ребёнка `father_id`/`mother_id`, у родителя `children_ids`.
- Если дата или факт неточны, в значении прямо указывается «дату уточнить».
- Файл должен оставаться валидным JSON: двойные кавычки, запятые между элементами, без комментариев.
